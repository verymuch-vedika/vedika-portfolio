# Portfolio site UI kit
Recreation of vedikamerchant.com built from the DS components. Source: `Home.dc.html` and `DPCL Case Study.dc.html` in this project.
- `HomeScreen.jsx` — hero, about, trusted-by, case-study stack, journey, banner quote, testimonials, contact, footer.
- `CaseStudyScreen.jsx` — sticky frosted nav, case hero (title, MetaList, cover), "On this page" TOC, disclaimer + TL;DR cards.
Click any case card to open the case study; "All case studies" / nav returns home. Desktop layout only (responsive variants live in the source DCs).
