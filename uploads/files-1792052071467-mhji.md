# Vedika | Personal Portfolio

Landing page inspired by the Wolfpixel “Personal Portfolio Website” Dribbble shot.
Built with Vite and vanilla HTML/CSS/JS.

## For contributors and AI agents

Read `AGENTS.md` (rules, commands, definition of done) and `DESIGN.md` (design system) before making changes.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Case study template

`case-study.html` (styles in `src/case.css`, script in `src/case.js`) is a service design
case study template, pre-filled for DPCL. Sections: overview (problem / approach / outcome),
challenge + "How might we", research (stats, methods, photos), insights + quote, current-state
journey map, service blueprint, co-design & testing, solution, impact, reflection, next case.

- Grey text with a dotted underline (`.cs-fill`) is placeholder copy. Replace it and delete the class.
- Striped frames (`.cs-ph`) are image slots. Put an `<img>` inside and remove the `<span>` label.
- For another case study, copy the file (e.g. `case-zmw.html`), add it to `vite.config.js`,
  and point the card's link in `index.html` at it.

## Editing

- **Copy**: all text lives in `index.html`, with one commented block per section
  (Hero, About, Featured carousel, Experiences, Promo, Latest Works, Blogs, CTA, Footer).
- **Images**: `public/images/`. Replace a file and keep its name, or update the `src` in `index.html`.
  - **Hero** (`hero.webp`) is a pre-processed transparent cutout with the silvertone grade and bottom
    fade baked in. To redo it with a new photo (macOS):
    `swift tools/subject-mask.swift photo.jpg /tmp/cut/mask.png`, then adjust the paths in
    `tools/silvertone.py` and run it (needs numpy and pillow).
  - Other portraits use the CSS `.silvertone` class in `src/style.css`.
  - Logos: `public/images/logos/`, shown in full colour.
  - Still-life images use `.soft` (gently desaturated colour).
- **Design tokens**: colours, font, gutter and container are CSS variables at the top of `src/style.css`.
- **Behaviour** (`src/main.js`): scroll reveals, count-up stats, an auto-scrolling draggable carousel,
  and the experience accordion (click, or hover on desktop).

Font: Inter Tight, a free stand-in for Aeonik. Photos: Unsplash (Unsplash License).
