# Design System: Vedika’s Portfolio

The source of truth for how this site looks, moves and reads. Anyone (human or AI) changing the
UI should follow this document. If you need to break a rule, update this file in the same change
and say why.

Reference: Wolfpixel “Personal Portfolio Website” (Dribbble 24978876). The aesthetic is
**monochrome, editorial, airy minimalism**: lots of whitespace, thin type, soft rounded cards,
and colour that comes almost only from imagery.

---

## 1. Principles

1. **Quiet by default.** Ink on light grey. Let photography and case-study covers carry the colour.
2. **One idea per block.** Generous spacing; never crowd a section to fit more in.
3. **Real content over decoration.** No filler stats, stock claims or lorem ipsum in shipped pages.
4. **Motion explains, never performs.** Small, eased, purposeful, and always off for reduced motion.
5. **Every state is designed.** Hover, focus, active, empty/“coming soon”, mobile, and reduced motion.
6. **Human voice.** Plain, warm, first person. See §9 Writing.

---

## 2. Tokens (`src/style.css` → `:root`)

Always use the variable, never the raw value, for these.

| Token | Value | Use |
|---|---|---|
| `--ink` | `#222222` | Text, dark pills, dark buttons, footer background |
| `--muted` | `#7b7b7b` | Body copy, captions, meta |
| `--hero-bg` | `#f3f3f3` | Hero, About, Case Studies, Trusted-by backgrounds. **Silvertone highlights clip to this.** |
| `--bg-grey` | `#f2f2f2` | Testimonials, CTA |
| `--surface` | `#f8f8f8` | Alternate light surface |
| `--white` | `#ffffff` | Cards |
| `--line` | `#e4e4e4` | Hairlines |
| `--font` | Inter Tight (Aeonik stand-in) | All text |
| `--gutter` | `clamp(20px, 4.3vw, 62px)` | Page side padding |
| `--container` | `1280px` | Max content width (`.container`) |
| `--ease` | `cubic-bezier(.22,.61,.36,1)` | Colour/opacity transitions |
| `--ease-out` | `cubic-bezier(.16,1,.3,1)` | Movement, reveals, hovers |

**Allowed neutral greys** (borders/fills only): `#dcdcdc` (pill borders), `#e3e3e3`/`#e6e6e6` (card
borders), `#efefef` (table rules), `#a3a3a3` (inactive nav), `#9a9a9a` (placeholder text).
Don’t introduce new greys. Pick the closest one.

**Accent colour:** none in the UI chrome. The only deliberate colours are:
- photos and covers, and the client logos (full colour);
- the ginger peekaboo cat;
- the service-blueprint failure dot `#d94a3d`.

## 3. Typography

Font: **Inter Tight** (300/400/500/600) from Google Fonts. Light (300) for display, 400 for
everything else, 500/600 only for rare emphasis.

| Role | Size | Weight | Tracking | Example |
|---|---|---|---|---|
| Display name | `clamp(104px, 14.4vw, 220px)`, lh .86 | 300 | −0.022em | Hero “Vedika” |
| Case hero title | `clamp(64px, 9vw, 136px)`, lh .9 | 300 | −0.035em | “DPCL” |
| H2 (`.h2`) | `clamp(34px, 3.3vw, 48px)`, lh 1.12 | 400 | −0.012em | Section titles |
| H2 XL (`.h2--xl`) | `clamp(40px, 4.6vw, 66px)` | 400 | −0.016em | Centred section titles |
| Card title | 20–36px | 400 | −0.01 to −0.02em | Case/timeline cards |
| Stat number | 38–64px | 300 | −0.03em | “+7”, “650+” |
| Body | 15–18px, lh 1.6–1.75 | 400 | 0 | Paragraphs (`.muted`) |
| Meta / nav | 13–15px | 400 | 0 | Labels, pills, nav |

Rules:
- Headings use `text-wrap: balance`. Don’t force line breaks with `<br>` except in display copy.
- Body copy is `--muted`; headings and key values are `--ink`.
- Never use ALL CAPS except the tiny blueprint line labels and the `.mini-pill`.

## 4. Layout & spacing

- Content sits in `.container` (max 1280px, side gutter `--gutter`). Full-bleed elements (the
  hero, banners, the timeline track) may break out, but their content still aligns to the container line.
- Section vertical rhythm: **~100–136px** desktop, **64–80px** mobile.
- Gaps: use **8 / 12 / 16 / 20 / 24 / 28 / 32 / 40 / 56 / 72px**. Avoid odd one-offs.
- Radius scale: **6px** (tiny images), **10–12px** (images inside cards), **14px** (cards), **16–20px**
  (large cards/banners), **999px** (pills, circle buttons), **54px** (CTA top corners).
- Breakpoints (max-width unless noted): **1200**, **1100**, **960** (main tablet switch), **720**, **640** (phone).
  Sticky stacking only runs at `min-width: 961px` **and** `min-height: 761px`.

## 5. Components (reuse these, don’t re-invent)

| Component | Class | Notes |
|---|---|---|
| Section eyebrow | `.eyebrow` | White pill with black dot. Short label, Title Case. |
| Underlined link with arrow | `.link-arrow` + `<svg><use href="#i-arrow"/></svg>` | Primary text CTA. The arrow nudges diagonally on hover. |
| Circle arrow button | `.circle-btn` (`--sm` / `--md` / `--lg` / `--light`) | Dark circle, ↗ arrow, appears on card hover. |
| Tag / pill | `.tag`, `.facts li`, `.mini-pill` | Rounded-full; `.mini-pill` is the dark uppercase year/category chip. |
| Stat | `.stat`, `.stat-card` | Light-weight number + muted caption. |
| Case card (stack) | `.stack-card` in `.case-stack` | Sticky deck on desktop. Must keep equal heights (JS sets `--card-h`). |
| Timeline | `.tl` (`.tl__bar`, `.tl__cards`, `.tl-card`) | One stop per **year**; multiple cards per year allowed (pips). Mobile uses `.tl__stepper`. |
| Quote banner | `.promo` | Dark rounded card over a dimmed B&W photo. |
| Quote card | `.quote-card` | White card, faint quote mark, tag, attribution. |
| Logo strip | `.trusted` | Full-colour logos, height-normalised per logo. |
| Case study page blocks | `src/case.css` (`.cs-*`) | TL;DR, HMW, stats, insights, journey map, blueprint, steps, features, impact, next case. |
| Placeholder copy/image | `.cs-fill`, `.cs-ph` | Visible “to do” styling. Remove when real content lands. |

Icons are inline SVG `<symbol>`s at the top of each HTML file (`#i-arrow`, `#i-down`, `#i-right`,
`#i-spark`, `#i-globe`, `#i-quote`, `#i-logo`). Add new icons there. The style is 1.5–1.6px stroke,
round caps, no fills except `#i-spark`/`#i-logo`/`#i-quote`.

## 6. Imagery

- **Portraits (silvertone).** Near-monochrome with a faint warm-silver cast:
  - deep blacks around 30–40/255;
  - high-key highlights clipped to `#F3F3F3`;
  - strong micro-contrast.

  The hero (`hero.webp`) is pre-processed with `tools/subject-mask.swift` and `tools/silvertone.py`. Other portraits use the `.silvertone` CSS class.
  **Never** show a colour portrait.
- **Still-life / covers.** Keep colour, softened: `.soft` = `saturate(.85) contrast(.95)`.
- **Journey photos.** Real candid photos, unfiltered, cropped with `object-fit: cover`.
- **Logos.** Transparent PNG, ~160px tall source, full colour.
- Always set `alt`. Decorative images use `alt=""`. Use `loading="lazy"` below the fold.
- Export at ≤ 2× display size. Prefer WebP/JPEG at q≈80. Keep `public/images` lean.

## 7. Motion

| Pattern | Spec |
|---|---|
| Scroll reveal | `.reveal` → fade + 28px rise, 1s `--ease-out`, stagger via `style="--d:.1s"` |
| Image hover | `.img-zoom`: 1.05 scale over 1.2s |
| Arrow hover | Arrow exits ↗ and re-enters (0.55s) |
| Card hover | Small lift (≤ 6px) or border darken. No big shadows. |
| Count-up | Numbers with `data-count` animate once on view |
| Sticky stack | Cards pin with an 18px peek. **No scroll-driven scaling or transforms** (it causes jitter). |
| Timeline | Snap so every card lands on the content line; flick = one card |

Rules: never animate layout properties on scroll; only `transform`/`opacity`. Anything that
moves must stop under `prefers-reduced-motion: reduce` (already handled globally; keep it that way).

## 8. Peekaboo cat (easter egg)

- Lives in `src/cat.js` (SVG rig + variants), `src/cat.css` and `src/peekaboo.js` (spots, counter, reward).
- **Shipped variant: `ginger`.** Others (classic, silhouette, line, chubby) are kept in `cat-lab.html` for reference.
- Eyes must stay **perfectly round**. No squash/stretch on the eye.
- The cat only peeks over real edges, one at a time, after scrolling pauses. It never covers interactive UI.
- Turn it off with `ENABLED = false`. It’s hidden for reduced motion.

## 9. Writing & content

- **No em dashes (—)** anywhere in visible copy, titles or alt text. Use a comma, a colon, a full
  stop, or restructure. (En dashes in date ranges like “2024 – Present” are fine.)
- First person, plain English, short sentences. No buzzword stacks, no “passionate about”.
- **Client confidentiality:** case studies use disguised names (DPCL, ZMW, Pearstream, Mature
  Money). Don’t write the real client name inside a case study. The “Trusted by” logo strip may
  show real brands.
- Stats must be real or clearly marked placeholders (`00`, `.cs-fill`).
- Dummy values still to replace: email `hello@vedika.design`.

## 10. Accessibility checklist (every change)

- [ ] Text contrast: body on `--hero-bg` uses `--muted` or darker; nothing lighter than `#7b7b7b` for real copy.
- [ ] Every interactive element is a `<a>` or `<button>` with a visible `:focus-visible` state.
- [ ] Icon-only buttons have `aria-label`.
- [ ] Decorative SVG/images are `aria-hidden` / `alt=""`.
- [ ] Works with keyboard (timeline bar supports arrows/Home/End).
- [ ] Nothing important depends on hover; touch has an equivalent.
- [ ] Reduced motion: no movement beyond opacity.

---

## 11. Responsive QA checklist

Test at **1728, 1440, 1280, 1100, 1000, 820 and 390** widths before calling UI work done:
- [ ] No horizontal overflow (`document.documentElement.scrollWidth === innerWidth`).
- [ ] No clipped shadows or text in scroll containers.
- [ ] Sticky elements stick for the full section and release cleanly (scroll both down **and** up).
- [ ] Cards: no blank areas, images fill their frames, equal heights where stacked.
- [ ] Mobile: tap targets ≥ 44px, text ≥ 14px for body.
