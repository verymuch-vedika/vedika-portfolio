The portfolio's only "button": an underlined text link with a ↗ arrow that nudges up-right on hover. Use for every CTA (Get in touch, View case study, Email me).
```jsx
<TextLink href="#contact">Get in touch</TextLink>
<TextLink href="#work" icon="arrow-right" iconLeft underline={false} size="s">All case studies</TextLink>
```
iconLeft flips the icon 180° (back links). There are no filled/primary buttons in this system — don't invent one.
